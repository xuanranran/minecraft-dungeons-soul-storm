# 我的世界地下城 2 灵魂风暴状态

查看灵魂风暴的当前地区、开启状态、倒计时和地区轮换时段。

**在线访问：https://xuanranran.github.io/minecraft-dungeons-soul-storm/**

## 功能

- 每 40 分钟开启一场、持续 20 分钟，跨日期连续轮换。
- 查看全部地区或指定地区未来 24 小时、48 小时及 7 天的时段。
- 点击当前地区旁的“查看掉落”或时间表地区名称，查看本地物品图片、参数、固定效果、可用附魔及各级效果；可按武器、盔甲部件、法器筛选。
- 北京时间显示；通过公共时间服务校时，失败时明确显示使用本机时间。
- 浅色、纯黑暗色、跟随系统三种外观。
- 默认 Mojangles 与方舟中文像素字体，可切换系统字体。
- 指定地区提前 0–120 分钟闹钟提醒，雷达音频循环播放，手动停止。
- 字体、外观、轮换校准与闹钟偏好保存在当前浏览器，不上传到服务器。

默认轮换起点为 **2026-10-06 12:00 安眠丘陵**；同一地区每 4 小时 40 分钟开启一次。

## 使用闹钟

展开“地区闹钟”，选择地区和提前分钟数，点击“保存并启用”。刷新或重新打开浏览器后，点击“测试闹钟”或页面解锁声音。

请保持网页打开。关闭网页、手机锁屏、浏览器暂停音频或系统休眠都可能阻止或延迟网页闹钟。它不能替代系统闹钟。

## 本地运行

需要 Node.js 22（检查）和 Python 3（本地静态服务）。

```sh
npm test
npm start
```

打开 `http://localhost:8080/`。页面不需要安装 npm 依赖。

## 部署

GitHub Pages 通过 `.github/workflows/pages.yml` 发布 `dist/`，推送到 `main` 后自动检查并更新网站。在仓库 Settings → Pages 中将 Source 设为 GitHub Actions。

公开版使用 TimeAPI.io 校时，WorldTimeAPI 为备用。网络时间服务不可用时沿用上次校准，首次校时失败则使用设备时间并显示提示。GitHub Pages 不运行 `server.py`，该文件仅保留用于原有 Debian 部署参考。
